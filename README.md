# Loon Custom Plugins

Personal optimized plugins for Loon on iOS/iPadOS.

## Plugins List

1. **Bilibili All-in-One (哔哩哔哩全能增强)**
   - 链接: `https://raw.githubusercontent.com/GoldenLoaf24h/Loon/main/Plugin/Bilibili_All_In_One.plugin`
   - 特性: 融合最新 ProtoBuf 二进制去广告、空降助手 (SponsorBlock)、直播间推广剔除、PCDN 加速重定向与港澳台番剧解锁。支持在 Loon 插件界面可视化配置。

2. **Zhihu Enhanced (知乎网页版增强)**
   - 链接: `https://raw.githubusercontent.com/GoldenLoaf24h/Loon/main/Plugin/Zhihu_Enhanced.plugin`
   - 特性: 屏蔽移动端“打开 App”弹窗与底栏横幅、自动展开全文、直链重定向（防 Safari 无效链接报错）。

3. **Prevent DNS Leaks (DNS 防泄露增强)**
   - 链接: `https://raw.githubusercontent.com/GoldenLoaf24h/Loon/main/Plugin/Prevent_DNS_Leaks.plugin`
   - 特性: 阻断动态测试子域名 DNS 泄露，绑定海外 DoH 安全解析。
